## 커밋 컨벤션

커밋 메시지는 `[타입] 내용` 형식으로 작성합니다.

| 타입 | 설명 |
| --- | --- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 수정 |
| `style` | 코드 포맷팅, 세미콜론 등 (로직 변경 없음) |
| `refactor` | 기능 변화 없는 코드 리팩토링 |
| `test` | 테스트 코드 추가/수정 |
| `chore` | 빌드 설정, 패키지 매니저 등 기타 작업 |

예시:

```
[feat] 회원 로그인 기능 추가
[fix] 세션 만료 시 예외 처리 오류 수정
[chore] 초기 프로젝트 구조 설정
```
